# כלי הערכת פרויקטי הפרדה מפלסית

כלי מבוסס מפה לציון פרויקטי הפרדה מפלסית: מציירים או מעלים את פוליגון הפרויקט, מעברי החצייה,
הדרך המרכזית הנחצית, ושני מסלולי הליכה (עם/בלי התוכנית) — ומקבלים בחזרה **ציון סביבה** (מחושב
משכבות GIS קבועות) ו**ציון תכנון** (חלקו אוטומטי, חלקו קלט ידני), וייצוא לאקסל.

## איך זה רץ בפועל (למי שלא מהתחום)

זו לא אפליקציה שמותקנת כמו תוכנה רגילה — היא מורכבת משני חלקים:

1. **שרת** — תוכנית Python קטנה (`uvicorn`/`FastAPI`) שרצה על המחשב שלך ברקע, מבצעת את כל
   חישובי ה-GIS (באפרים, חיתוכים, צפיפויות), וממתינה לבקשות.
2. **דף אינטרנט** — הממשק שרואים בדפדפן (המפה, הטפסים) — הוא בעצם דף HTML/JavaScript רגיל
   שמדבר עם השרת ברקע כדי לבקש חישובים ותוצאות.

כשמריצים את הפקודה למטה, זה "מדליק" את השרת על המחשב המקומי שלך (לא באינטרנט, לא נגיש
לאף אחד מלבדך) על כתובת מיוחדת (`127.0.0.1` — זה תמיד אומר "המחשב הזה עצמו") ופתח (`8123` —
סתם מספר שמזהה את השרת הספציפי הזה מבין כמה שירותים שיכולים לרוץ על אותו מחשב). הדפדפן
מתחבר לכתובת הזו בדיוק כמו שהיה מתחבר לאתר אינטרנט רגיל, רק שה"אתר" יושב על המחשב שלך.
כל עוד חלון הטרמינל שבו הרצת את הפקודה פתוח, השרת פעיל; אם תסגור אותו, תצטרך להריץ את
הפקודה מחדש כדי לפתוח שוב את הכלי.

## דרישות

- Python 3.11+ עם `geopandas`, `shapely`, `pandas`, `openpyxl`, `pyogrio` (כבר קיימות בסביבת
  ה-anaconda של המחשב הזה), וגם `fastapi` ו-`uvicorn` (מותקנות עם `pip install -r backend/requirements.txt`).

## הרצה מקומית

```bash
pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload --port 8123
```

פותחים בדפדפן: http://127.0.0.1:8123/ — השרת גם מגיש את הממשק (`frontend/`) כקבצים סטטיים,
כך שאין צורך להריץ שום דבר נוסף.

## שכבות הרקע (ציון הסביבה)

`backend/data/` מכיל את 3 שכבות הרקע הקבועות שציון הסביבה מחושב מולן, נבנות מקבצי המקור ב-
`data_sources/raw/` (ראו `data_sources/README.md`) על ידי `python backend/scripts/build_reference_data.py`:

- **`traffic_zones.geojson`** — נתונים אמיתיים: 905 אזורי תנועה של תחבורה לירושלים, מחוברים
  לתחזית אוכלוסין/מועסקים לשנת הבסיס 2020 (השדות `population_2020`/`employment_2020`). לקובץ
  המקור יש גם עמודות לשנים 2025 עד 2050 — עדיין לא מחוברות לכלי.
- **`built_up_area.geojson`** — נתונים אמיתיים: שכבת שטח בנוי ארצית (פוליגון ענק אחד), מפוצלת
  לחלקים ומסוננת לאזור ירושלים. החישוב תמיד מול הגרסה המלאה (~90 אלף חלקים); המפה מציגה רק
  עותק מסונן (שטח ≥ 10,000 מ"ר, כ-5,500 חלקים) כדי לא להכביד על הדפדפן.
- **`intersections.geojson`** — נתונים אמיתיים: שכבת צמתים ארצית (~269 אלף נקודות, כל רשומה
  כבר צומת אמיתי עם 3+ מפגשי דרכים), מסוננת לאזור ירושלים. המפה מציגה רק צמתים עם 4+ מפגשי
  דרכים (כ-15 אלף), החישוב תמיד מול השכבה המלאה.

לעדכון השכבות (למשל שנת תחזית אחרת, או קובץ מקור מעודכן): לעדכן את הנתיבים/שמות השדות ב-
`backend/config.py` אם צריך, להריץ מחדש את `build_reference_data.py`, ולהפעיל את השרת מחדש.

**קלט לכל פרויקט** (מצוירים או מועלים מחדש בכל פעם, לא שכבות קבועות): פוליגון הפרויקט, מעברי
החצייה (אפשר כמה), הדרך המרכזית, ושני מסלולי ההליכה (עם/בלי התוכנית).

## מה מוכן ומה עוד פתוח

- **ציון סביבה**: מוכן במלואו ורץ על נתונים אמיתיים (צמתים, אוכלוסין, מועסקים, שטח בנוי).
- **ציון תכנון**: מרווח מעברי החצייה ופער אורך מסלול ההליכה מחושבים אוטומטית. שאר תתי-המדדים
  (שינוי מפלסי, שיפור תח"צ, סיבת הקמה, רוחב דרך, תחושת מקום, חסימה חזותית, פעילות רחוב,
  בטיחות) הם קלט ידני בסולם -1/0/1 בינתיים, עד שיוגדרו כללי חישוב מדויקים יותר.
- **שנת תחזית**: רק עמודות 2020 מחוברות; אפשר בהמשך לחשוף בורר שנה (עד 2050).

## מבנה הפרויקט

```
backend/       שרת FastAPI, לוגיקת הציונים, טעינת שכבות רקע, ייצוא אקסל
frontend/      ממשק Leaflet (JS רגיל, בלי שלב build)
data_sources/  קבצי המקור הגולמיים + build_reference_data.py
```
